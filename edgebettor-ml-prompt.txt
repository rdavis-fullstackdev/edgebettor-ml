Feature engineering
In src/nfl\_ev/data/features.py build per-game rows with both teams:
• rolling windows per team: last 3 and last 5 games for EPA/play offense, EPA/play defense, success rate, pass rate, run rate, neutral pace, red zone trip rate, third down rate, pressure rate if available
• rest days, home field flag, dome flag, travel miles using team city coords (include a simple mapping file for coords)
• matchup diffs: home\_offense\_rolling\_minus\_away\_defense\_rolling and vice versa
• market inputs: closing spread, closing total, closing moneyline for both teams where available
• target columns:
– y\_home\_win (1 if home won)
– y\_home\_cover\_vs\_closing (1 if home covered closing spread)
– y\_over\_total\_vs\_closing (1 if total points > closing total)
Split logic in src/nfl\_ev/data/splits.py:
• time-based split: train on seasons <= S-2, validate on S-1, test on S
• also support expanding-window CV

Pricing formulas
src/nfl\_ev/odds/pricing.py:
• american odds to implied probability:
if odds > 0: implied = 100 / (odds + 100)
if odds < 0: implied = -odds / (-odds + 100)
• per \$1 stake expected value:
if odds > 0: payoff = odds / 100
if odds < 0: payoff = 100 / -odds
EV = p \* payoff - (1 - p) \* 1
• edge = p - implied
• for spreads and totals use side-specific prices spread\_price\_home, spread\_price\_away, total\_over\_price, total\_under\_price

EV computation
For each market:
• Moneyline
– p\_home\_win vs moneyline\_home
– p\_away\_win vs moneyline\_away
• Spread
– p\_home\_cover vs spread\_price\_home
– p\_away\_cover vs spread\_price\_away
• Total
– p\_over vs total\_over\_price
– p\_under vs total\_under\_price
Compute EV and edge for each option. Rank by EV, then by edge, then by AUC head reliability from metrics.json.
